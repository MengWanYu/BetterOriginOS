# BetterOriginOS 0.1.0 · iQOO Z8（OriginOS 5）系统体验补丁

> 帖子可直接粘贴版。发布前请自查最后一节的"取件信息"是否与手上一致。

## 这是什么

给 **iQOO Z8（OriginOS 5 / Android 15）** 做的一组 LSPosed 模块补丁，解决几个每天都能碰到、
但官方一直不改的问题：

- 通知条太"安卓"，想要 iOS / OriginOS 6 那种干净排布
- 同一个 App 多条通知被系统合并成一张"应用类别卡"，看着就乱
- 通知中心那张媒体卡跟系统风格对不上
- 文件管理重命名只能输 56 个字符，长下载名直接被掐断
- 照片选择器里自己建的相册"消失"，只能看到默认相册

**所有功能默认关闭**，进 App 里按需打开；不想要了关掉开关重启 SystemUI 就回到原生，
不写死系统、不改分区、不换 APK。

## 功能

### 1. 通知条 iOS 化（默认关闭）

收起态原地重排，不碰系统的模板绑定链，所以**点击打开、长按菜单、滑动删除这些原生手势全部保留**。

- 38dp 应用图标（自适应图标满幅裁边），标题 / 正文同列左对齐
- 同一个 App 的多条通知**拆成独立卡片**，不再被合并
- 卡片参数可选 iOS 规格（16dp 边距 / 8dp 间距 / 20dp 圆角）或 OS5 原生
- 覆盖 `base / big / bigText / inbox / bigPicture` 五种模板；
  `messaging / conversation`（微信、短信那类）用同规格的覆盖行，**聊天内容不丢**
- MediaStyle 通知自动让给下面的媒体卡，两个功能不打架
- 日间 / 夜间 / 字体缩放 1.3 都真机复测过

### 2. 通知中心媒体卡（默认关闭）

- 两种样式：**OS5 原子随身听** / **Material You**，下拉菜单里带预览图，选完所见即所得
- 进度条可拖动调节播放位置

### 3. 文件管理重命名修复（默认关闭）

- 重命名长度上限 **56 → 85 字符**

### 4. 媒体选择器相册修复（默认关闭）

- 照片选择器显示全部自建相册

### 5.【测试功能】OS6 折叠堆叠通知

同一个 App 多条通知折叠成一叠：正面是最新一条，卡片下方逐层露边，图标右上角是深色条数徽标。
点卡片右上角的箭头展开成组内列表（**点卡片本身是打开 App**，不会误触），再点箭头收起，带 180ms 过渡动画。

同时把 AOSP 那个"通知装不下就压成底部一条图标收纳栏"的行为去掉了，改成继续往下排 + 滚动，
跟 OS6 / iOS 的逻辑一致。

> ⚠️ **这一项是测试功能，可能不稳定。** 弹窗横幅（heads-up）与堆叠卡的联动、阿拉伯语 RTL 环境都还没实测。
> 想稳一点就把「分组方式」选成**完全分离**；万一出现异常，把「通知」功能关掉重启 SystemUI 即可恢复。

## 怎么装

1. 需要 **root（KernelSU）+ LSPosed**
2. 安装 `BetterOriginOS-v0.1.0-beta.apk`，在 LSPosed 里启用
3. **作用域三个都要勾**：`SystemUI`、`MediaProvider`、`文件管理`
4. 打开 BetterOriginOS App，进对应功能卡片开开关、选样式
5. 按 App 内提示重启 SystemUI（或 `adb shell "su -c 'killall com.android.systemui'"`）

## 已知限制（0.1 阶段，先说清楚）

- 只适配 **iQOO Z8 / OriginOS 5 / Android 15**，别的机型系统版本没验证过，别硬上
- heads-up 横幅仍是 vivo 自绘的那颗胶囊，本版没动
- iOS 化只做收起态，**展开态保持原生**
- App 自带自定义布局（RemoteViews）的通知不改
- 卡片背景材质 / 模糊沿用系统，不是自绘
- RTL（阿拉伯语等）未实测：本机没法给 SystemUI 单独切语言

出问题麻烦带上：**机型 + 系统版本 + 开了哪几个功能 + 截图/录屏**，最好再说明是"通知"还是"媒体卡"引起的。
