# 更新日志

面向使用者的版本说明。内部过程与取证记录在 `out/DEVLOG.md`，这里只写"你会看到什么变化"。

## 0.1.3-beta（2026-11-11）

本版主线是把模块搬到 **Android 14 / Funtouch 14.1（OS4）** 机型上跑通，并把
Android 11 样式切歌后"左半边纯黑"这条老问题从三处根因上修掉。

### 新增（OS4 / Android 14 适配）

- **相机快门样式**：拍照键换成 OS5 的原子环（白环 + 白心），只改静态外观 ——
  按下缩放、录像切红盘、语音快门等原生反馈全部保留。
- **桌面动效增强**：恢复被厂商预配置关闭的「打开 / 退出应用动画」与「壁纸缩放动画」，
  并把系统设置里被隐藏的「桌面过渡动画」入口放回（设置 → 动态效果 → 界面动态效果）。
  模块卡片里另有四档档位（无动效 / 高效 / 中等 / 舒适），切换立即生效。
- **通知条大图标**：42dp 圆角应用图标进内容列、标题与图标同排（OS4 上同样生效）。
- **媒体卡三种样式在 OS4 上可用**：OS5 原子随身听、Material、Android 11；
  适配了 OS4 展开态使用厂商自有模板的情况。
- **媒体选择器相册修复在 OS4 上生效**：相册页从只有 相机 / 截图 / 下载 三个，
  恢复为全部相册（实测 43 个）。

### 新增（通用）

- **样式切换立即生效**：改样式不用等下次换歌，卡片当场重建。

### 优化

- **OS5 原子随身听样式的背景模糊**：此前把封面缩到 20×20 再拉伸，整张卡糊成一片色块；
  改为 96px + 三轮可分离盒式模糊，得到真正的"磨砂取色底"，保留封面的色块结构。
- **黑卡窗口缩短**：打开面板后从"没绑上会话"到正确取色，约 3.5 秒 → 约 1.5 秒。

### 修复

- **Android 11 样式切歌后左侧一大片纯黑**（多首曲目必现）：
  ① 卡片建立时封面还没投递 → 这张卡永久拿不到封面、永远不取色；
  ② 会话绑定时取色与封面的处理顺序颠倒 → 浮雕用建卡时的黑色底画了一张；
  ③ 卡片底色过渡动画在面板闲置时冻结在第一帧。
  三处已分别修正，取色现在跟着封面走。
- **OS5 原子随身听样式切歌时右侧小封面闪现**：换歌时系统会重新显示原生封面，
  现在所有样式由同一套守卫在同帧内藏回。
- **录像模式下拍照键被换成白色原子环**（盖住原生红色录像盘）：改为读取按钮的
  无障碍描述判断拍照 / 录像。
- **重复注入**：Vector 会重复派发加载事件并重建模块类加载器，导致同一批挂钩反复叠加，
  已加进程级去重。
- **媒体选择器落点探测**用错了一个 action 名，误报"本机没有照片选择器"。

### 验证

- 离线自检 24 项全绿。
- OS4 真机：媒体卡度量验收 76 通过 / 0 失败（三种样式逐一切换）。
- OS4 真机：大图标几何验收全绿（42dp、内容列 left=36dp、标题同排）。
- OS4 真机：相机拍照正常出图、录像态原生红盘完整；相册页 43 个相册全量显示。

### 已知问题

- **Android 11 样式下，部分曲目（如《读心术》）切歌后左侧仍可能残留深色区域**，
  仍在定位。规避：把媒体卡样式切到「OS5 原子随身听」。
- 少数系统应用（如「Android 系统」）的分组摘要行，左上角图标仍可能缺失或空白。
- 桌面动效增强依赖桌面版本的混淆名，桌面升级后可能失效（失败会在日志自报）。

### 更新后

- LSPosed 作用域：新增 `com.android.camera`（快门）、`com.bbk.launcher2` 与
  `com.android.settings`（桌面动效）；原有 `com.android.systemui`、
  `com.android.providers.media.module`、`com.android.filemanager` 保持不变。
- 重启一次系统界面（或重启手机）生效。

## 0.1.2-beta（2026-11-05）

### 新增

- **通知中心媒体卡：Android 11 原生卡（Ocean）风格**
  照 Android 11 真机数值复刻通知栏里那张音乐卡：封面浮雕渐变、按封面取色的卡片底色与文字、
  进度条与两端时间、动作按钮着色。OS5 与 OS3 都能用。
- **这张卡的收起态小播放器**
  通知折叠时按 Android 11 的收起模板排布：标题 / 歌手在左，上一首·暂停·下一首排在它右侧，
  封面在右上角、不带进度条；展开仍是原来的整张卡。
- **通知条美化 →「OS5 通知观感」**（可选：关闭（本机原生）/ OS5 复刻）
  把 OS5 的通知几何移植到本机：连续角卡片、收纳栏间距、浮动一键清除（配合"原生优化"样式使用）。
- **原生优化样式在 OS5 上的适配**：大图标、文字列对齐、圆角与间距按 OS5 原生观感。

### 优化

- **深色 / 浅色封面下都看得清**：文字与按钮的颜色改为按卡片底色的**实际对比度**在黑、白两族里取
  更高的一族（此前浅桃色封面会被选中白字，对比度只有约 2.5:1）；所有动作按钮统一跟随正文颜色，
  不再只有暂停键变色。
- **切歌更顺**：新封面到达时先按新图取色、再启动 320ms 淡入，消掉"先变淡看不清、颜色才跟上"的窗口；
  同一张图只是换底色时不再重放一次淡入。
- **进度条不再抖**：进度条改用自有标识并自己接管横向手势。此前借用系统的那个进度条 id，系统每轮重排
  会把它一起藏掉 —— 表现是切歌瞬间进度条消失、两端时间挤到一起。拖动仍然正常。
- **OS3（Android 13）通知行的时间戳**：不再把时间搬到行尾，回到原生左上槽并全程不动
  （修掉"点展开时时间从右边跑到左边、到左边又闪回右边"）。

### 修复

- **展开 / 收起通知时左上角小图标闪现一下**：判定"这一行有没有我们的顶替大图标"时读了图标此刻的
  透明度与可见性，而过渡帧这两个值会被系统改写，于是被误判成"没有顶替"、把原生小图标放回去。
  判据改为只看归属与有没有内容，过渡全程不再露出原生小图标。
- **部分分组摘要行左上角变成空白圆角边框**（vivo服务 等）：压制原生小图标的判据与收集判据同源，
  并且顶替图标必须真的有内容才允许压制；已经压坏的行会自动恢复。

### 已知问题

- 少数系统应用（如「Android 系统」）的分组摘要行，左上角图标仍可能缺失或空白，仍在定位。
- 通知条美化的 iOS 风格仍是测试版，边界情况持续维护。
- 「媒体选择器相册修复」在 OriginOS 3 上没有落点：该系统内没有可达的照片选择器，功能会装上但不触发。

### 更新后

- 在 LSPosed 中保持作用域勾选：`com.android.systemui`（通知与媒体卡）、
  `com.android.providers.media.module`（照片选择器）、`com.android.filemanager`（重命名修复）。
- 重启一次系统界面（或重启手机）生效；样式在设置 App 对应功能卡里切换。
- 适用机型与系统：iQOO Z8，OriginOS 5（Android 15）/ OriginOS 3（Android 13），需 KernelSU/root + LSPosed。
